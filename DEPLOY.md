# O! Journey — публикация без локального терминала

## Текущая структура
Исходный проект находится в папке `o-journey 2/` (с пробелом). Это **не** готовый production-сайт: `index.html` — демонстрационный интерфейс, `backend/` — FastAPI, а цены гостиниц и экскурсий пока тестовые.

## Быстрый публичный просмотр интерфейса (Vercel)
1. В Vercel → Add New → Project → Import Git Repository выберите `ulko31/o-journey`.
2. **Root Directory** установите `o-journey 2`.
3. **Framework Preset:** Other (статический сайт).
4. **Build Command:** оставить пустым, **Output Directory:** `.` (корень выбранной папки).
5. Нажмите Deploy и проверьте полученный URL на компьютере и телефоне.

**Важно:** это только публикация фронтенда. Внешние обращения к `/api/...` на статическом Vercel-сайте не заработают без отдельного backend и прокси. Не показывайте тестовые предложения как реальные.

## Backend (отдельно)
Разместите FastAPI на Render или совместимом Python-хостинге. Из корня проекта команда запуска:
`python -m uvicorn backend.app:app --host 0.0.0.0 --port $PORT`
Для Render установите Root Directory: `o-journey 2`, Build Command:
`pip install -r backend/requirements.txt`
После деплоя проверьте `/docs` и погодные запросы.

## Следующий этап интеграции
Нужно подключить frontend к публичному API по безопасному HTTPS URL, настроить CORS или единый origin/прокси, затем повторить интеграционные тесты. **Только после этого** можно считать опубликованное приложение функциональным.

## Обязательные проверки перед показом жюри
- Главная страница без белого экрана.
- Отсутствуют системные браузерные `prompt()` / `alert()` в пользовательском пути.
- Карта видна и маркеры соответствуют выбранному маршруту.
- «Хочу посетить» не запрашивает отзыв о ещё не посещённом месте.
- Данные о тарифах и погоде помечены своим действительным статусом.
- В репозитории и клиентском коде нет секретов.

Не изменяйте конкурсный репозиторий `ostrovok-hackathon-2026/oops` до проверки его структуры и прав доступа.
